### 2.4 数据流架构

```
                    +-----------+
                    |   页面     |  (pages/*.vue)
                    +-----+-----+
                          |
                  绑定/事件
                          |
                    +-----v-----+
                    |  API 层   |  (utils/api.ts)
                    +-----+-----+
                          |
              +-----------+-----------+
              |                       |
         +----v----+           +-----v-----+
         | 后端 API |           | 模拟数据   |
         | localhost:8720       | mockData.ts
         +---------+           +-----------+
              |
         +----v----+
         |  Agent3  |
         | 匹配引擎  |
         +---------+
```

**核心设计原则**：
- 前端通过 `api.ts` 统一调用，不直接依赖具体数据源
- `USE_BACKEND` 变量控制是否调用后端 API：`true` → 后端 / `false` → 模拟数据
- 后端不可用时自动降级到模拟数据，页面始终可用
- 模拟数据与后端返回的 JSON 结构保持**字段命名一致**（camelCase）

### 3.4 Agent3 匹配流程

```
+------------+    +--------------+    +-------------+
|  简历文件   | -> | ResumeParser | -> | MatchEngine |
|  PDF/Word  |    |  .parse()    |    | .match()    |
|  TXT       |    |  → Resume    |    |  → Match    |
+------------+    +--------------+    +------+------+
                                              |
                         +--------------------+--------------------+
                         |                    |                    |
                    +----v----+         +-----v-----+       +-----v-----+
                    | Gap     |         | Skill     |       | 经验/职责  |
                    | Analyzer|         | Match     |       |  匹配     |
                    +---------+         +-----------+       +-----------+
                         |                    |                    |
                         +--------------------+--------------------+
                                              |
                                        +-----v-----+
                                        | Report     |
                                        | Builder    |
                                        | .build()   |
                                        | → Match    |
                                        |   Report   |
                                        +-----------+
```

**三维匹配权重体系**：

| 维度 | 权重 | 策略 |
|------|------|------|
| 技能匹配 | 0.45 | 候选人技能集 vs 岗位必需/加分技能（精确匹配 + 语义等价） |
| 经验匹配 | 0.30 | 工作年限 vs 要求、学历 vs 要求、行业背景 |
| 职责匹配 | 0.25 | 候选人工作/项目经历 vs 岗位核心职责（关键词覆盖） |

**降级策略**：
- LLM 不可用时 → 规则模式（正则匹配，低置信度）
- MongoDB 不可用时 → 模拟模式（返回结构一致的模拟数据）
- 后端 API 不可用时 → 前端自动使用本地 mock 数据

### 3.5 数据转换层

后端在返回数据到前端前，通过 `_snake_to_camel()` 函数自动将 Agent3 的 snake_case 字段转换为前端期望的 camelCase：

| Agent3 原始字段 | 前端期望字段 |
|-----------------|-------------|
| `overall_match_score` | `overallMatchScore` |
| `required_skills_match_rate` | `requiredSkillsMatchRate` |
| `optional_skills_match_rate` | `optionalSkillsMatchRate` |
| `skill_matches` | `skillMatches` |
| `position_name` | `positionName` |
| `dimension_scores[].dimension` | `dimensionScores[].dimension` |
| `dimension_scores[].score` | `dimensionScores[].score` |
| `skill_matches[].skill_name` | `skillMatches[].skillName` |
| `skill_matches[].is_required` | `skillMatches[].isRequired` |

## 5. API 接口规范

### 5.1 通用响应格式

```json
{
  "ok": true,
  "data": { ... }    // 具体数据
}
```

错误时：
```json
{
  "detail": "错误描述"
}
```

### 5.2 端点详述

#### POST /api/parse-resume
- **Content-Type**: `multipart/form-data`
- **参数**: `file` (文件, 支持 .pdf/.doc/.docx/.txt)
- **返回**: `{ "ok": true, "data": ResumeProfile }`

#### POST /api/match-position
- **Content-Type**: `multipart/form-data`
- **参数**: `file` (文件) + `position` (岗位名称)
- **返回**: `{ "ok": true, "data": [MatchReport] }`

#### POST /api/match-all
- **Content-Type**: `multipart/form-data`
- **参数**: `file` (文件)
- **返回**: `{ "ok": true, "data": [MatchReport] }` （Top-5）

#### GET /api/positions?search=关键词
- **返回**: `{ "items": [PositionInfo], "total": number }`

```typescript
// 检查后端状态

// 指定岗位匹配
```

### 6.2 Agent1 扩展（新岗位发现 + 能力演化）

**后端接入**：
```python
# backend/server.py 中新增端点
@app.post("/api/agent1/discover")
async def agent1_discover():
    """触发新岗位发现流程"""
    orch = Agent1Orchestrator()
    try:
        result = orch.run_discovery()
        return {"ok": True, "data": result}

@app.get("/api/agent1/skills-trend")
```

### 6.5 USE_BACKEND 开关

```typescript
// utils/api.ts
const API_BASE = "http://localhost:8720/api"
const USE_BACKEND = false  // ← 改为 true 即可连接真实后端

async function callApi(endpoint: string, options?: RequestInit): Promise<any | null> {
  if (!USE_BACKEND) return null  // 直接跳过
  try {
    const res = await fetch(API_BASE + endpoint, {
      ...options,
      signal: AbortSignal.timeout(10000),
    })
    if (!res.ok) return null
    return await res.json()
  } catch {
    return null  // 后端不可用时自动降级到 mock 数据
  }
}
```
