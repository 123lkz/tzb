整体架构概览：系统采用六层架构设计，从底层数据源到顶层应用展示逐层递进。数据源采集层已在 网站数据爬取.html 中完成核心技术实现，后续层为本项目需要新开发的内容。

逐层拆解说明

第一层：数据源层

输入

包含7大主流招聘平台（智联招聘、BOSS直聘、猎聘网、前程无忧、58同城、拉勾网、应届生求职网）以及用户上传的简历文件（PDF/Word格式）。后续还可扩展至技术博客、开源社区（GitHub）、行业报告等更多数据源。

第二层：数据采集层

已有实现

基于 Playwright + MongoDB 的多平台招聘数据爬虫系统。

BaseSpider 基类

统一封装浏览器管理、多标签页并发、反检测机制、Motor异步MongoDB批量写入。

7平台爬虫子类

各平台独立实现多步爬取流程（智联8步、BOSS 4步、猎聘6步等），分别处理Cookie验证、分页、详情提取。

反爬机制

UA轮换、代理轮换、请求延迟、鼠标轨迹模拟、动态Cookie管理、JS验证挑战处理。

原始存储

MongoDB jobs_raw 集合存储原始数据，包含job_id、title、company、salary、city、experience、education、source等字段。

第三层：数据处理层

核心能力

对爬取后的原始数据进行标准化清洗与多源交叉验证，解决数据"时滞、噪声、抄袭"三大问题。

DataCleaner 清洗引擎

薪资格式统一（k/万/元多格式→数值化）、技能关键词抽取、城市/经验/学历标准化、标题清洗。输出至 jobs_clean。

多源交叉验证引擎

跨平台职位合并去重；时滞检测：历史数据对比，标注过时要求；抄袭检测：JD文本相似度对比；噪声过滤：统计异常值+大模型语义一致性检查。

第四层：AI 智能体分析层

本层是系统的核心创新所在，围绕赛题三大核心难题设计了三个专用智能体，协同完成从数据到知识的转化。

智能体1：新兴岗位发现与定义 + 既有岗位能力更新

新兴岗位挖掘

对清洗后的JD文本进行主题建模（BERTopic/LDA）→ 关键词聚类 → 发现尚未被标准化分类的岗位 → 与已有岗位库对比识别新岗位候选。

岗位定义生成

使用大模型（LLM） + RAG 技术，基于相似JD片段生成岗位名称、核心职责、必备/加分技能、典型行业应用场景。支持人工审核。

既有岗位能力更新

对比同一岗位不同时间窗口的JD技能频率变化 → 识别新增/删除/修改的能力项 → 标注变化来源与置信度 → 输出diff更新日志。

能力图谱构建

将岗位-技能关系结构化，构建技能层级树，关联技能→岗位→行业，形成技能级粒度的全景图谱。

智能体2：数据质量治理（时滞/噪声/抄袭 + 幻觉防控）

时滞处理

建立时间序列模型追踪技能提及率变化，区分长期趋势与短期噪声。滞后JD中的能力要求通过近期高频技能进行修正。

噪声与抄袭检测

使用文本相似度（SBERT/BERTScore）计算JD间余弦相似度，超过阈值标记为模板化；统计方法识别异常薪资、不符实际的技能组合。

幻觉防控

多模型共识机制：同一能力由多个LLM独立推理，仅共识结果入图；结合知识库约束（已知技能树+技术栈依赖关系），输出置信度评分与数据溯源。

智能体3：简历解析与人岗差距分析

简历解析

基于NER（命名实体识别）+ LLM 提取简历中的技能项、工作经历、项目经验、教育背景。支持PDF/Word格式，准确率>=90%。

人岗匹配诊断

将简历技能向量与目标岗位技能图谱进行语义匹配，计算匹配度、覆盖度、缺失项、冗余项。精确到技能点级别。

差距分析与学习路径

基于缺失技能生成针对性改进建议与岗位学习路径（推荐课程→实践项目→认证考试），输出清晰差距报告。

第五层：知识图谱层

图数据库 (Neo4j/Nebula)

存储岗位-技能-行业-公司之间的复杂关系网络。节点：岗位、技能、行业、公司、工具栈；边：requires、depends_on、belongs_to、evolves_from等。

动态演化引擎

每个节点和关系带时间戳版本标记，支持按时间回溯历史图谱状态；定期自动增量更新；变更日志记录每次修改的来源数据与置信度。

第六层：应用展示层

后端API层 (FastAPI)

提供RESTful API：图谱查询、人岗匹配、简历上传解析、岗位搜索筛选。支持前端所有数据交互。

全景图谱仪表盘

基于D3.js/ECharts交互式可视化：按技术栈/级别切换视图；力导向图/树形图/桑基图多模式展示；下钻到技能点级详情。

人岗匹配诊断界面

用户输入技能或上传简历 → 展示匹配百分比 → 技能缺失雷达图 → 具体差距项 → 点击每一项查看学习路径推荐。

技术路线总结

已实现（现有爬虫系统）

7平台数据爬取（Playwright + MongoDB）；反爬机制（UA轮换、代理、指纹混淆）；原始数据存储 jobs_raw；基础数据清洗（薪资/技能/城市标准化）。

待开发核心模块

多源交叉验证引擎（时滞/噪声/抄袭检测）；三大AI智能体；图数据库与动态演化引擎；交互式全景图谱可视化仪表盘；人岗匹配诊断界面。

关键技术选型建议

  • 大模型：推荐讯飞星火（主办方），备选 GPT-4 / DeepSeek / Qwen
  • RAG框架：LangChain / LlamaIndex + 向量数据库（ChromaDB / Milvus）
  • 图数据库：Neo4j（社区版）或 NebulaGraph（分布式场景）
  • 知识图谱可视化：D3.js（力导向图）/ ECharts（关系图）/ Vis.js
  • 后端框架：FastAPI（轻量异步）
  • 前端框架：React / Vue3 + TypeScript
  • 语义匹配：SBERT / BERTScore 用于JD相似度计算和技能匹配
  • NER命名实体识别：基于LLM的实体抽取或微调BERT-CRF模型
