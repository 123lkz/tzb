# 岗好遇见——新一代信息技术岗位能力动态演化与匹配平台
## 技术设计大纲（修订版）

---

## 第一章 项目概述与需求分析

### 1.1 项目背景与问题提出
- 新一代信息技术产业快速发展，岗位需求持续变化
- 传统招聘平台岗位分类滞后，新岗位出现难以及时识别
- 求职者与岗位之间信息不对称，人岗匹配效率低

### 1.2 核心痛点与目标用户
- **企业端**：招聘需求描述不标准，难以精准定位人才
- **求职者端**：难以了解岗位技能要求动态变化，职业规划缺乏数据支撑
- **高校端**：课程设置与产业需求脱节，缺乏实时岗位能力数据

### 1.3 项目目标
- 构建新一代信息技术岗位全景图谱
- 实现多源数据采集、清洗与标准化
- 支持新岗位自动发现与既有岗位能力演化分析
- 提供智能简历解析与人岗匹配服务

### 1.4 典型应用场景
- 企业招聘需求分析
- 求职者技能差距诊断与学习路径规划
- 高校专业设置与课程优化参考
- 产业人才需求趋势洞察

### 1.5 项目定位与成果形态
- 岗位全景图谱平台（Web 应用）
- 岗位能力画像与关系数据库
- 技能趋势分析报告

## 第二章 总体解决方案与技术架构

### 2.1 系统设计理念
- 数据驱动 + AI 增强
- 三层解耦架构：前端展示、后端服务、Agent 引擎
- 可扩展设计：预留知识图谱、自动调度等接口

### 2.2 系统总体架构
- 前端：Nuxt 3 + Vue 3 + TypeScript + TailwindCSS
- 后端：FastAPI + Uvicorn（端口 8720）
- 数据库：MongoDB（recruitment 库，10 个集合）
- Agent 引擎：三个智能体协同

### 2.3 全流程业务闭环
`
爬虫采集 → 数据清洗（jobs_clean）→ NLP 画像生成（Agent2）
  → 关系挖掘 → 新岗位发现（Agent1）→ 简历匹配（Agent3）
  → 前端可视化展示
`

### 2.4 三类智能体协同机制
- **Agent1**：新岗位发现与技能演化（聚类 + 新颖性检测 + 趋势分析）
- **Agent2**：NLP 画像与数据治理（画像生成 + 质量检查 + 幻觉防护）
- **Agent3**：简历解析与岗位匹配（多格式解析 + 多维匹配）

### 2.5 关键技术与系统部署
- LLM：DeepSeek API（通过 Agent2 客户端统一调用）
- 嵌入模型：sentence-transformers（all-MiniLM-L6-v2）
- 部署：本地服务器（前端 :8570 + 后端 :8720 + MongoDB :27017）

## 第三章 多源数据采集、治理与证据体系

### 3.1 数据源体系设计
- 五大招聘平台：BOSS 直聘、拉勾、猎聘、前程无忧、智联招聘
- 数据格式：岗位信息（标题、公司、薪资、技能、城市等）

### 3.2 数据采集与原始数据存储
- 爬虫采集清洗后写入 MongoDB jobs_clean 集合
- 每条记录包含 title / company / salary / skills / city / experience 等字段

### 3.3 数据分层与标准结构（已实现）
- **原始层**：jobs_clean（100 条，爬虫写入）
- **画像层**：nlp_profiles（61 条，Agent2 生成）
- **关系层**：relation_profiles（100 条）/ jobs_kg（23 条）
- **分析层**：agent1_output（210 条）/ match_reports（19 条）

### 3.4 数据清洗与标准化
- 薪资格式统一（如 15k-25k → 15K-25K）
- 技能列表去空去重
- 日期格式标准化（YYYY-MM-DD）
- 字段缺失校验

### 3.5 重复、抄袭、时滞与噪声处理
- 爬虫层去重：同一平台+职位+公司+城市 去重
- Agent2 层去重：跨平台相似度合并（dedup 模块）
- 数据质量检查：完整性、一致性、时效性、抄袭检测、噪声检测

### 3.6 多源互证与证据链设计
- RelationProfile 包含 evidence + counter_evidence 双向证据
- RelationProvenance 记录数据溯源信息
- 低置信度关系进入 audit_queue 等待人工审核

## 第四章 岗位能力建模与 JD 智能解析

### 4.1 岗位能力概念模型（已实现）
- 岗位画像（PositionProfile）：核心职责、必备技能、加分技能、行业领域
- 技能画像（SkillProfile）：摘要、前置知识、相关技术、典型应用

### 4.2 岗位技能分类与标准词典
- 行业推断函数 _infer_industry()：基于技能关键词映射
- INDUSTRY_KEYWORDS：覆盖人工智能、大数据、云计算等 10+ 行业

### 4.3 JD 文档解析与实体抽取
- Agent2 NLP 画像模块：从 jobs_clean 提取岗位和技能实体
- LLM 辅助生成岗位描述摘要

### 4.4 技能标准化与实体消歧
- 技能名称统一大小写
- LLM 共识机制处理模糊技能名称

### 4.5 JD 解析结果与典型案例
- 岗位画像示例：大模型算法工程师（核心职责 + 必备技能 + 加分技能）
- 技能画像示例：SQL（前置知识 + 相关技术 + 应用场景 + 熟练度分级）

## 第五章 新岗位发现与既有岗位能力演化

### 5.1 岗位动态分析框架（已完整实现）
- Agent1 管线：job_clusterer → novelty_detector → label_generator → skill_evolution

### 5.2 新岗位候选发现
- HDBSCAN 聚类 + sentence-transformers 嵌入
- 岗位标题语义聚类 → 识别新兴岗位类别

### 5.3 新岗位可信度评估与自动定义
- novelty_score > 0.75 判定为新岗位
- LLM 自动生成岗位名称、描述、核心职责、技能要求

### 5.4 既有岗位能力变化识别
- 技能趋势分析：按季度窗口统计技能出现频率
- EvolutionDetector 判断趋势：上升 / 下降 / 新增 / 稳定 / 衰退

### 5.5 岗位能力演化量化与版本管理（部分实现）
- 技能趋势数据已生成（periods + frequency + change）
- 多版本管理待实现

### 5.6 新岗位与既有岗位示范案例
- 新岗位示例：多模态 AI 工程师（已写入 agent1_output）
- 技能趋势示例：RAG 技能从无到有的增长趋势

## 第六章 岗位-能力图谱构建与动态演化

### 6.1 图谱本体与核心要素架构（接口预留）
- 节点类型：岗位 / 技能 / 行业 / 公司

### 6.2 图谱构建与入图规则（部分实现）

- 增量更新机制待开发

### 6.5 全景图谱查询与可视化演示

## 第七章 简历解析、人岗匹配与学习路径规划

## 第八章 大模型幻觉防控与可信保障机制

### 8.1 幻觉风险类型识别（已实现）
- LLM 生成内容幻觉（岗位描述、技能关系）
- 关系挖掘错误关联
- 标签生成偏差

### 8.2 数据约束与 RAG 检索增强机制（待实现）
- 当前依赖 LLM 直接生成
- RAG 检索增强尚未集成

### 8.3 多模型、规则与图谱协同校验（已实现）
- Agent2 hallucination_prevention 模块
- 多轮共识机制（consensus_rounds）
- 反向证据收集（counter_evidence）

### 8.4 置信度与证据追溯
- 关系置信度评分（0.0 ~ 1.0）
- RelationProvenance 记录数据溯源（created_by、llm_model）
- evidence + counter_evidence 双向证据链

### 8.5 隐私、安全伦理与人工审核
- audit_queue 低置信度关系等待人工审核
