# 后端技术设计文档
> 版本：v1.0 · FastAPI + Agent 架构 · 

## 1. 技术栈概览
| 层级 | 技术 | 说明 |
|---|---|---|
| Web 框架 | FastAPI | 异步 API 服务 |
| 服务器 | Uvicorn | 端口 8720 |
| 数据库 | MongoDB | recruitment 库 |
| LLM | DeepSeek API | 通过 Agent2 客户端 |
| 嵌入模型 | all-MiniLM-L6-v2 | Agent1 聚类 |

## 2. 系统架构
前端 (:8570) → HTTP → 后端 API (:8720) → Agent 引擎 → MongoDB

公开 API：/api/health, /api/positions, /api/parse-resume, /api/match-position, /api/match-all
Insights API：/api/insights/overview, skills-trend, new-positions, audit-queue, run-discovery

## 3. 目录结构
backend/server.py + uploads/ + 清理脚本
agents/agent1/ — job_discovery, skill_evolution, output_adapter
agents/agent2/ — nlp_profile, data_quality, dedup, hallucination_prevention, llm
agents/agent3/ — resume_parser, job_matching

## 5. Agent1 — 新岗位发现
run_pipeline(): cluster → novelty_detect → label_generate → skill_evolution → output
结果写入 agent1_output，status: pending → confirmed/dismissed

## 6. Agent2 — NLP 画像
ProfileStore(MongoDB) + Pydantic Schemas(Skill/Position/RelationProfile)
审核流程：confidence < 0.85 → audit_queue → 人工审核 → jobs_kg

## 7. Agent3 — 简历匹配
ResumeParser(.word/.pdf/.txt) → ResumeProfile
MatchEngine → MatchReport(多维得分 + 差距分析)
结果存入 match_reports

## 8. 部署
1. mongod → 2. python backend/server.py → 3. npm run build → 4. node .output/server/index.mjs
