## 系统架构总结

### 六层架构（自顶向下）

```
应用展示层（红）：FastAPI 后端 · 全景图谱仪表盘 · 人岗匹配诊断
知识图谱层（粉）：Neo4j/NebulaGraph · 动态演化引擎
AI 智能体分析层（紫）核心创新：Agent1/Agent2/Agent3
数据处理层（琥珀）：DataCleaner 清洗引擎 · 多源交叉验证引擎
数据采集层（青）已有实现：BaseSpider · 7平台爬虫 · 反爬
数据源层（蓝）：7大招聘平台 · 简历上传
```

### 数据流转路径

招聘网站/简历 -> Playwright 爬虫 -> jobs_raw -> DataCleaner + 交叉验证 -> jobs_clean -> 三大 Agent -> jobs_kg -> Neo4j -> FastAPI -> 可视化展示

### 已实现 vs 待开发

| 模块 | 状态 | 说明 |
|------|------|------|
| 数据采集 | 已有实现 | 7 平台爬虫 + 反爬机制 + MongoDB 存储 |
| 数据清洗 | 部分实现 | 基础薪资/技能/城市清洗已有，交叉验证引擎需开发 |
| AI 智能体 | 待开发 | 三大 Agent 均为新开发 |
| 图数据库 | 待开发 | Neo4j/NebulaGraph 部署与数据导入 |
| 动态演化 | 待开发 | 时间戳版本追踪、增量更新 |
| 前端界面 | 待开发 | 全景图谱仪表盘、人岗匹配界面 |
| 后端 API | 待开发 | FastAPI 服务、图谱查询接口 |
