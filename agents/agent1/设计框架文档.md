# Agent 1 设计框架文档

> **所属项目**：多源异构数据驱动岗位和能力图谱构建与动态演化分析研究  
> **所属层级**：AI 智能体分析层（紫色层）  
> **核心职责**：新岗位发现 + 能力更新  
> **依赖**：读取 `jobs_clean`，复用 Agent2 的 LLMClient 和 ProfileStore  
> **最后更新**：2026-07-22

---

## 一、设计动机

### 1.1 要解决什么问题

在新一代信息技术领域，岗位和技能处于快速演变中。Agent1 解决两个核心问题：

| 问题 | 现状 | Agent1 的做法 |
|------|------|-------------|
| 岗位目录滞后 | 静态岗位分类无法覆盖新兴岗位 | 从海量招聘数据中自动聚类发现未被收录的新岗位 |
| 技能需求漂移 | 岗位技能需求随时间变化 | 检测同一岗位的技能需求时序变化 |

### 1.2 在整个图谱构建流程中的位置

```
Agent1 负责"发现"——找新东西
Agent2 负责"验证"——确保东西是可信的

Agent1输出 -> MongoDB agent1_output -> Agent2校验 -> jobs_kg -> Neo4j
```

## 二、系统架构

### 2.1 六层架构中的位置

```
AI 智能体分析层（紫）
  |-> Agent1: 新岗位发现 + 能力更新  <-- 本模块
  |-> Agent2: 数据质量治理 + 幻觉防控
  |-> Agent3: 简历解析 + 人岗匹配
```

### 2.2 Agent 1 内部模块

```
Agent1Orchestrator (main.py)
├── job_discovery/
│   ├── JobClusterer       文本聚类引擎
│   ├── NoveltyDetector    新兴性检测
│   ├── LabelGenerator     LLM辅助标注
│   └── schemas.py         数据模型
├── skill_evolution/
│   ├── SkillTrendAnalyzer   技能趋势分析
│   ├── EvolutionDetector    演化检测
│   └── schemas.py           数据模型
├── output_adapter/
│   ├── ChangeRecordBuilder  变更记录组装器
│   ├── GraphInterface       图谱接口适配器
│   └── schemas.py           统一输出模型
├── prompt_templates.py
├── config.py
└── tests/
```

### 2.3 数据流

```
jobs_clean (MongoDB)
  |
  ├──> job_discovery/
  |     聚类 -> 与已有PositionProfile对比 -> LLM标注
  |     -> NewPositionSuggestion[]
  |
  ├──> skill_evolution/
  |     按岗位分组 -> 技能频次时序分析 -> 演化检测
  |     -> SkillChangeSuggestion[]
  |
  └──> output_adapter/
          统一包装 -> 写入 MongoDB agent1_output
```

---

### NewPositionSuggestion 核心字段

| 字段 | 说明 | 来源 |
|------|------|------|
| suggested_name | 岗位名称 | LLM / 统计 |
| core_responsibilities | 核心职责（3-5项）| LLM 生成 |
| suggested_required_skills | 必需技能 | LLM / 统计 |
| suggested_optional_skills | 加分技能 | LLM / 统计 |
| typical_applications | 典型行业应用场景（1-3项）| LLM 生成 |
