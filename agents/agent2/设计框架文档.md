> **所属项目**：多源异构数据驱动岗位和能力图谱构建与动态演化分析研究  
> **所属层级**：AI 智能体分析层（紫色层）  
> **核心职责**：数据质量治理 + 基于自然语言画像的幻觉防控  
> **论文启发**：*Transparent and Scrutable Recommendations Using Natural Language User Profiles*  
> **最后更新**：2026-07-15

## 一、设计动机

### 1.1 要解决什么问题

在岗位和能力图谱的构建过程中，来自多个招聘平台的数据存在三类核心问题：

| 问题 | 传统做法 | 我们的做法 |
|------|----------|------------|
| 时滞 | 忽略时效，直接用旧数据 | TimelinessChecker 标记过时技能 + 失效岗位 |
| 噪声/抄袭 | 简单去重 | PlagiarismChecker + NoiseDetector 多维度检测 |
| 幻觉 | embedding 相似度（黑箱，不可解释）| NL Profile 显式推理（白盒，可审计可修正）|

### 1.2 论文启发：从黑箱 embedding 到白盒 NL Profile

*Transparent and Scrutable Recommendations Using Natural Language User Profiles* 的核心思想：

> 用可读、可审查的自然语言用户画像替代黑箱 embedding 向量来做推荐，使得推荐透明（用户能理解为什么被推荐）且可修正（用户能编辑自己的画像）。

我们将其映射到知识图谱场景：

| 论文概念 | Agent 2 映射 |
|----------|-------------|
| User Profile（自然语言描述）| SkillProfile / PositionProfile（自然语言画像）|
| 推荐基于 profile 的显式推理 | 技能-岗位关系基于 NL profile 的 LLM 显式推理 |
| 用户可审查/修改自己的 profile | 专家可审查/修改技能和岗位的自然语言画像 |
| 推荐有透明理由 | 每条知识图谱边有完整的 NL justification |

**核心转变**：

```
传统黑箱：Skill embedding -> Position embedding -> 余弦相似度 -> 阈值判断（无法解释 0.82 的含义）
我们的白盒：Skill NL Profile + Position NL Profile -> LLM 显式推理 -> 输出决策+理由+置信度+溯源
```

## 二、系统架构

### 2.1 六层架构中的位置

```
AI 智能体分析层（紫）
  |-> Agent1: 新岗位发现 + 能力更新
  |-> Agent2: 数据质量治理 + 幻觉防控  <-- 本模块
  |-> Agent3: 简历解析 + 人岗匹配
```

### 2.2 Agent 2 内部模块

```
Agent2Orchestrator (main.py)
  +-- data_quality/         可插拔数据质量检查
  |     CheckerRegistry + AbstractDataQualityChecker
  |     Completeness / Consistency / Timeliness / Plagiarism / Noise
  +-- nlp_profile/          自然语言画像系统
  |     SkillProfileBuilder / PositionProfileBuilder / RelationProfileBuilder
  +-- hallucination_prevention/  基于 NL Profile 的幻觉防控
        ConsistencyEngine（白盒推理）/ ConfidenceScorer / ConsensusManager
```

### 2.3 数据流

```
MongoDB jobs_clean
  -> data_quality/registry.run_all(record)
     -> quality_report (存 quality_reports)
  -> nlp_profile/ -> SkillProfile + PositionProfile (存 profiles)
  -> hallucination_prevention/ -> 对每个候选关系
     -> ConsistencyEngine -> LLM 白盒推理
     -> ConsensusManager -> 多轮共识
     -> ConfidenceScorer -> 四维评分
     -> 高置信度 -> 写 jobs_kg
     -> 低置信度 -> 入 audit_queue
```

## 三、模块详解

### 3.1 自然语言画像系统

三种画像类型：

- **SkillProfile**：技能的唯一标识、名称、分类、NL 概述、前置知识、相关技术栈、典型场景、熟练度分级、行业趋势
- **PositionProfile**：岗位唯一标识、名称、NL 概述、核心职责、必需/加分技能、行业领域、薪资范围、经验要求
- **RelationProfile**：关系标识、起点/终点类型、关系类型、有效标志、置信度、NL 推理过程、证据链、反面证据、建议操作、溯源信息

构建流程：jobs_clean -> 提取技能项/岗位 -> 聚合相关JD片段 -> LLM 生成画像 -> MongoDB profiles

### 3.2 幻觉防控

**白盒推理流程：**

1. 候选关系到达
2. ConsistencyEngine 加载 SkillProfile + PositionProfile
3. LLM 接收结构化 Prompt，做显式推理
4. ConsensusManager 多轮/并行推理，聚合结果（多数投票 + 方差分析）
5. ConfidenceScorer 四维评分：
   - LLM 置信度（权重 0.40）
   - 证据强度（权重 0.30）
   - 解释质量（权重 0.15）
   - 来源多样性（权重 0.15）
6. 高置信度（>=0.85）-> 写 jobs_kg；低置信度 -> audit_queue

**与传统方法对比：**

传统 embedding 方法：黑箱、不可审计、需重新训练、误报难定位
NL Profile 白盒方法：可解释、可审计、零样本、专家可直接编辑

### 3.3 可插拔数据质量接口

**接口：**
- AbstractDataQualityChecker（抽象基类）
- CheckerRegistry（注册中心+批量调度）
- CheckResult（标准化输出）

**扩展：** 继承 AbstractDataQualityChecker -> 实现 check() -> 自动注册

**内置 5 个检查器：**
- CompletenessChecker：必填字段完整性
- ConsistencyChecker：薪资/经验一致性
- TimelinessChecker：时效性与过时技能
- PlagiarismChecker：JD 模板化检测
- NoiseDetector：异常值+不合理技能组合

## 三、去重模块（新增）

### 3.1 设计动机

《职位数据存在多重冗余：

- 精确重复：同一公司同岗位同城市的完全重复记录
- 跨平台重复：同一岗位在不同招聘平台的重复发布
- 内容重复：不同公司发布的同一岗位，JD 描述高度相似

### 3.2 三阶段去重流程

三步去重：精确去重 → 跨平台去重 → 内容去重

`ash
python -m agents.agent2.main --dedup

## 五、运行说明

### 5.1 前置条件

- Python 3.10+，已安装 requirements.txt 依赖
- MongoDB 服务运行中（连通 recruitment 数据库）
- DeepSeek API 凭证（可选，未配置时启用模拟模式）

### 5.2 配置环境变量

在项目根目录创建 .env 文件（或直接复制 .env.example）：

```
XF_API_KEY=your_api_key_here
XF_API_SECRET=your_api_secret_here
XF_APP_ID=your_app_id_here
XF_API_BASE=wss://spark-api.xf-yun.com/v4.0/chat
XF_MODEL=deepseek-chat
MONGODB_URI=mongodb://localhost:27017
MONGODB_DB=recruitment
LOG_LEVEL=INFO
```

### 5.3 运行命令

```
# 完整流水线
python -m agents.agent2.main

# 仅数据质量检查
python -m agents.agent2.main --check-only

# 仅构建自然语言画像
python -m agents.agent2.main --profile-only

# 仅运行幻觉防控
python -m agents.agent2.main --hallucination-only

# 指定批次
python -m agents.agent2.main --batch 200
```

### 5.4 运行测试

```
cd my
python -m pytest agents/agent2/tests/ -v
```

当前 40 个测试，覆盖：数据质量检查器 16、注册中心 5、数据模型 10、幻觉防控 9。

### 5.5 输出产物

| MongoDB 集合 | 内容 | 来源 |
|-------------|------|------|
| nlp_profiles | SkillProfile + PositionProfile | nlp_profile/ |
| relation_profiles | RelationProfile（含置信度+证据+溯源）| hallucination_prevention/ |

## 六、扩展指南

### 新增数据质量检查器

```python
from agents.agent2.data_quality.base_checker import (
    AbstractDataQualityChecker, CheckResult, CheckerType,
)

class MyChecker(AbstractDataQualityChecker):
    @property
    def name(self) -> str: return "my_checker"
    @property
    def check_type(self) -> CheckerType: return CheckerType.CUSTOM

    def check(self, record: dict) -> CheckResult:
        # 自定义逻辑
        return CheckResult(checker_name=self.name, passed=True, score=1.0, details="OK", flagged_items=[])
```

### 切换 LLM

在 llm/client.py 中修改 LLMClient 或新增客户端，保持 chat(messages, temperature) -> str 接口。

### 调整阈值

在 config.py 中修改 CONFIDENCE_HIGH_THRESHOLD / CONSENSUS_MIN_ROUNDS 等。
