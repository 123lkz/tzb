# Agent 3 操作说明

> **所属项目**：多源异构数据驱动岗位和能力图谱构建与动态演化分析研究  
> **最后更新**：2026-07-16

---

## 一、概述

Agent 3 是「简历解析 + 人岗匹配」智能体，是整个系统的最终价值出口。它接收简历文件，解析为结构化画像，然后与 Agent2 构建的岗位知识图谱做匹配，输出诊断报告。

### 整体数据流

```
简历文件 (PDF/Word/TXT)
  → FileExtractor (文件提取)
  → SectionSplitter (段落分割)
  → ResumeParser (LLM + 规则混合解析)
  → ResumeProfile (结构化简历画像)
  → MatchEngine (三维匹配)
     ↓ 技能匹配 (0.45) + 经验匹配 (0.30) + 职责匹配 (0.25)
  → GapAnalyzer (差距分析)
  → MatchReport (匹配诊断报告)
  → MongoDB + 控制台输出
```

## 二、前置条件

| 条件 | 说明 |
|------|------|
| Python 3.10+ | 已安装 |
| MongoDB | 运行中，连通 `recruitment` 数据库 |
| DeepSeek API 密钥 | 已配置在 `.env` 中 |
| PyMuPDF | `pip install PyMuPDF`（解析 PDF 简历） |
| python-docx | `pip install python-docx`（解析 Word 简历） |

### 环境变量（.env）

项目根目录的 `.env` 文件已包含：

```
DEEPSEEK_API_KEY=your_deepseek_api_key_here
DEEPSEEK_API_BASE=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
MONGODB_URI=mongodb://localhost:27017
MONGODB_DB=recruitment
```

> 注：未配置 API 密钥时自动降级到**规则模式**，仅提取技能列表和基本信息。

## 四、命令参考

### parse — 仅解析简历

```powershell
python -m agents.agent3.main parse <简历文件路径>
```

参数：

| 参数 | 必填 | 说明 |
|------|------|------|
| `<简历文件路径>` | 是 | 支持 .pdf / .docx / .txt |

### match — 解析并匹配

```powershell
python -m agents.agent3.main match <简历文件路径> (--position <岗位名> | --match-all)
```

参数：

| 参数 | 必填 | 说明 |
|------|------|------|
| `<简历文件路径>` | 是 | 简历文件 |
| `--position <岗位名>` | 与 `--match-all` 二选一 | 指定岗位名称 |
| `--match-all` | 与 `--position` 二选一 | 全局匹配所有岗位，Top-5 |

项目没有安装 MongoDB Compass 或 mongosh 时，可用 Python 直接查询：

```powershell
python -c "exec(open(r'路径').read())"
```

更简单 —— 直接在终端运行：

```powershell

python -c "from agents.agent2.nlp_profile.profile_store import ProfileStore; s=ProfileStore(); import json; [print(json.dumps(r,ensure_ascii=False,indent=2)[:300]) for r in s.db['resume_profiles'].find({},{'_id':0})]; s.close()"
```

**推荐安装 MongoDB Compass**（图形化工具）：

1. 从 https://www.mongodb.com/products/compass 下载安装
2. 连接字符串：`mongodb://localhost:27017`
3. 选择 `recruitment` 数据库

| 集合 | 内容 |
|------|------|
| `resume_profiles` | 简历画像 |
| `match_reports` | 匹配报告 |

| `jobs_kg` | 岗位-技能关系图谱 |

## 七、备用：规则模式

当 DeepSeek API 不可用时（无网络 / 密钥未配置），系统自动降级到规则模式：

```
解析完成: 张三
  方式: rule, 置信度: 0.40     ← 规则模式标记
  技能: 16 项                    ← 规则模式只能提取技能
  教育: 0 段, 工作经历: 0 段    ← 需要 LLM 才能提取
  项目: 0 段
```

规则模式使用正则表达式提取姓名、电话、邮箱、教育背景关键词和技能列表，不依赖任何外部 API，离线可用。

## 八、常见问题

### LLM 返回 mock 结果

现象：解析方式显示 `llm`，置信度 `0.85-0.91`，但技能/教育/工作全空

原因：
1. DeepSeek API 网络不通（HTTP 连接被防火墙拦截）
2. API 密钥未配置或配置错误

解决：
- 检查 `.env` 中的 `DEEPSEEK_API_KEY` 是否正确
- 检查网络连通性：`python -c "import requests; print(requests.get('https://api.deepseek.com').status_code)"`
- 若网络不通，系统会自动降级到规则模式（方式=rule）

### 匹配无结果

现象：匹配结果显示 Top-0

原因：MongoDB 中没有岗位画像（需要先运行 Agent2 流水线）

解决：
```powershell
python -m agents.agent2.main          # 构建岗位/技能画像
python -m agents.agent3.main match test_resume.txt --match-all
```

### Windows 终端中文乱码

在运行前执行：

```powershell
chcp 65001
```
